**Going over target:** 

The app simply warns the user and suggests one useful tip. It does not stops the user from logging more entries.

If the logging was stopped, the user might feel discouraged to log entries furthermore making tracking difficult. Also, sometimes due to discouragement, the user might even stop using the app, so to stop the user from quitting, the app simply gives a waring and suggests a tip

**Weird numbers (like a 500,000km car trip):** 

Instead of accepting or rejecting absurd inputs, the app prompts the user to confirm before logging. It catches typos but does not assume you are wrong.

Most of the times, the absurd values are just typos or accidentally holding a key for too long. Thus, the app confirms it with the user whether they entered the value they meant to enter and gives a little comparison with practical scenarios so the user knows that the value is likely very high.

**What counts as "the week":** 

7 days of a week are marked by small dots names M to S on the dashboard telling the user which days they have logged in.

Usually, people tend to start a new tracking journey from Monday. That is why it felt suitable to use a monday to sunday format to make a week. In order to align with the thinking of majority of people.
