**Carbon Gauge**

A simple carbon footprint tracker. Log stuff like car trips, flights, electricity use, and meals, and it works out the CO₂ for you using fixed factors. Set a weekly target and it tracks how close you are.

**Track**

Climate tech

**Hackathon ID:** AZIS-547RSV

**Tech**

Just HTML, CSS, and JavaScript — no frameworks, no build tools. It saves everything in the browser's local storage instead of using a real database, so it's a single file you can just open.

**How to run it**

Download index.html and open it in your browser.No installs needed.
